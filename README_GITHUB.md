# MelmanAPP — cloud build

This project can be built on GitHub Actions without Android Studio/AndroidIDE.

## Upload
Upload the contents of this folder to the root of the `MelmanAPP` repository on GitHub.

Then open **Actions → Build MelmanAPP APK → Run workflow**. After the run finishes, open the workflow run and download the **MelmanAPP-debug** artifact. It contains `app-debug.apk`.
